## CORE DETECTION MODULES

### 1. data_feed.py
- Fetch OHLCV candles from Twelve Data REST API
- Support multiple pairs and timeframes
- Cache last 200 candles per pair/timeframe
- Return pandas DataFrame with columns: open, high, low, close, volume, datetime
- Handle API rate limits gracefully with retry logic (exponential backoff)
- Function: get_candles(pair, timeframe, outputsize=200)

### 2. structure.py — Market Structure
Implement the following with exact SMC logic:

**Swing Detection:**
- identify_swings(df, lookback=5): detect swing highs and lows using rolling window
- A swing high = candle high is highest in lookback candles on both sides
- A swing low = candle low is lowest in lookback candles on both sides

**BOS (Break of Structure):**
- Bullish BOS: price closes above the last confirmed swing high
- Bearish BOS: price closes below the last confirmed swing low
- Tag the candle index and price level where BOS occurred

**CHoCH (Change of Character):**
- In a downtrend: bullish CHoCH = first BOS to the upside
- In an uptrend: bearish CHoCH = first BOS to the downside
- Distinguish CHoCH from continuation BOS

**Trend State:**
- Return current bias: BULLISH, BEARISH, or RANGING
- Based on sequence of HH/HL (bullish) or LH/LL (bearish)

### 3. order_blocks.py — Order Block Detection
**Bullish OB:**
- Last bearish (red) candle before a strong bullish impulse that caused a BOS
- Valid OB = price has not returned to mitigate it yet
- Store: OB high, OB low, OB midpoint, candle index, creation time

**Bearish OB:**
- Last bullish (green) candle before a strong bearish impulse that caused a BOS
- Valid OB = price has not returned to mitigate it yet

**OB Validation:**
- Mark OB as mitigated when price closes through the 50% level of the OB
- Remove mitigated OBs from active list
- Keep last 5 unmitigated OBs per direction

**Breaker Block:**
- An OB that has been mitigated and price has broken through
- Flip its bias (bullish OB becomes bearish breaker and vice versa)

### 4. fvg.py — Fair Value Gap Scanner
**Bullish FVG:**
- Candle[i-1].high < Candle[i+1].low = gap between them
- Gap must be at least 0.1% of price to be significant

**Bearish FVG:**
- Candle[i-1].low > Candle[i+1].high

**FVG Status:**
- Fresh: price has not entered the gap
- Partially filled: price entered but did not close through
- Filled: price closed through — invalidate

**Inverse FVG:**
- A filled FVG that now acts as support/resistance

### 5. liquidity.py — Liquidity Mapping
**Equal Highs/Lows (EQH/EQL):**
- Scan for 2+ swing highs within 0.05% of each other = EQH (buy-side liquidity)
- Scan for 2+ swing lows within 0.05% of each other = EQL (sell-side liquidity)

**Previous Day/Week Highs and Lows:**
- PDH, PDL: previous daily candle high and low
- PWH, PWL: previous weekly candle high and low
- These are prime liquidity targets

**Liquidity Sweep Detection:**
- Price wicks above EQH/PDH then closes back below = buy-side liquidity swept
- Price wicks below EQL/PDL then closes back above = sell-side liquidity swept
- A sweep followed by reversal is a high-probability signal

### 6. sessions.py — Kill Zone Timing
Define ICT kill zones in UTC:
- London Open KZ: 07:00–09:00 UTC
- New York Open KZ: 13:00–15:00 UTC
- London Close KZ: 11:00–12:00 UTC
- Asian Range: 00:00–05:00 UTC (range definition, not entry)

Functions:
- is_in_kill_zone(): returns True/False + zone name
- get_current_session(): returns ASIAN, LONDON, NEW_YORK, OFF
- Signals generated outside kill zones get lower confluence score

### 7. premium_discount.py — Premium/Discount Zones
- Identify the most recent major swing high and swing low (HTF)
- Calculate 50% equilibrium (EQ) level
- Price above EQ = Premium zone (look for sells)
- Price below EQ = Discount zone (look for buys)
- Add Fibonacci levels: 0.705 (OTE entry zone), 0.79, 0.886
- Tag each signal with PREMIUM, DISCOUNT, or EQUILIBRIUM

### 8. confluence.py — Multi-Factor Scorer
Score each potential signal from 0–10 based on:

| Factor | Points |
|--------|--------|
| HTF bias aligns with LTF signal direction | +2 |
| Price at valid unmitigated OB | +2 |
| FVG present in same zone | +1 |
| Liquidity swept before entry | +2 |
| In kill zone | +1 |
| In premium/discount zone (correct side) | +1 |
| CHoCH confirmed on LTF | +1 |

- MIN_CONFLUENCE_SCORE from .env (default 3) = minimum to send alert
- Return score, signal direction (LONG/SHORT), and list of active factors
